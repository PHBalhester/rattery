# Contributing

1. Discuss substantial behavior changes first.
2. Use Node 24 and npm ci; keep generated reports/dependencies out of Git.
3. Preserve determinism, snapshot compatibility and payment boundaries.
4. Add meaningful regression coverage for behavioral changes.
5. Run build, typecheck:api, test:ci and check:publication.
6. Explain the problem, final behavior, validation and limits in your PR.

Use fictional fixtures. Never attach credentials, private captures or unlicensed media. Keep UI copy in English and Chinese. A wallet connection must not silently become a signing or transaction request.

Review dependencies and preserve license notices. Do not edit lockfiles by hand. Original-project licensing is not yet selected; coordinate contribution terms with the maintainer.
