# Security policy

RATTERY operates a live shared colony with wallet authentication and token-burn care. Mint records project ownership; it does not create an NFT. This project does not claim an independent security audit.

Never include seed phrases, private keys, RPC credentials, session tokens or personal data in public issues.

## Reporting

Private vulnerability reporting is not currently enabled on this repository. Until a private channel is established, open an issue requesting a confidential reporting channel without including vulnerability details, exploit steps or credentials. Do not publish a vulnerability report in that issue.

Provide affected versions, impact and a minimal redacted reproduction through an agreed private channel. Use local fixtures; do not test destructively against public services or other wallets.

## Scope and maintenance

Main is the active development branch. Published releases describe their component scope; a documentation release does not mean every production component was redeployed. Response times are not guaranteed.

See [operations](docs/OPERATIONS.md), [release checklist](docs/RELEASE.md) and [validation](README.md#validation-and-limitations).
