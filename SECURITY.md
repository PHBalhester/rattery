# Security policy

RATTERY is pre-production. Real minting and paid care are disabled. Never submit seed phrases, private keys, RPC credentials, session tokens or personal data in an issue.

Use **Security → Report a vulnerability** when available. If disabled, ask the maintainer to establish a private reporting channel before sharing details. Do not publish exploitation details or send credentials through social media.

Provide a minimal reproduction, affected version, impact and redacted environment. Use local fixtures; do not test destructively against public services or other wallets.

Only main is actively developed; no stable production release is maintained yet. Response times are not guaranteed. Local tests are not an independent audit. See docs/RELEASE.md.
