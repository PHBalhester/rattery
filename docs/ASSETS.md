# Assets and reproduction

Runtime GLBs in public/models/ are generated by project Blender scripts. Raw .blend files, backups and renders stay local because they can carry embedded machine paths and redundant data.

Use Blender 4.5 LTS. scripts/blender/run.sh supports BLENDER_BIN, a local tool directory or Blender on PATH. Factory settings and disabled embedded-script autoexecution are used.

```sh
bash scripts/blender/run.sh --background --python scripts/blender/create_rat.py
bash scripts/blender/run.sh --background --python scripts/blender/create_gait_study.py
bash scripts/blender/run.sh --background --python scripts/blender/export_rat_lods.py
bash scripts/blender/run.sh --background --python scripts/blender/export_gait_lods.py
npx --no-install tsx scripts/export-habitat.ts
bash scripts/blender/run.sh --background --python scripts/blender/create_habitat.py
```

Inspect regenerated models in studio views and rerun motion/clearance checks. Export results can vary across Blender versions.

## Fonts
Fraunces and IBM Plex Mono are self-hosted; public/fonts/ includes OFL licenses and source/hash records. Preserve notices.

## Audio
Dusty Decks — Conifers is optional local media. Possession of a copy does not establish redistribution rights. The MP3 is excluded from Git. Obtain appropriate rights before supplying public/audio/conifers.mp3 to a deployment through an authorized asset pipeline.

No autoplay; user opt-in, loop and 25% volume. Missing media gives an accessible error without stopping the colony.

Reference images/commercial models are not included as reusable assets. Original project licensing is described in LICENSE.md.
