- [ ] Verify final RATTERY token and contract behavior.
- [ ] Server SIWE challenges/sessions and authenticated authorization.
- [ ] Durable ownership and atomic intent/receipt processing.
- [ ] End-to-end payment rejection, replay and recovery tests.
- [ ] Independent financial security review.
- [ ] Verify deployed endpoints, headers, TLS and rate limits.
- [ ] Snapshot publication, monitoring and recovery.
- [ ] Long-term memorial/genealogy retention.
- [ ] Physical Android/iOS, Safari and mobile networks.
- [ ] Accessibility, performance and long-session review.
- [ ] Asset/audio permission and project license decision.
- [ ] Clean-checkout tests and secret scanning.
- [ ] GitHub visibility, branch protection, private reporting and available secret-protection settings.
- [ ] Incident response and rollback plan.

Local mock tests deliberately do not mark production gates complete.
