# Diamond Aurora

One operator-created female newborn named Aurora, requested by the project owner. It is explicitly created through an audited operator transaction, not won by the random birth lottery.

Persistent coatBucket 10000 selects violet/turquoise Diamond aurora, crystalline tail shading and a faceted diamond attached to the final caudal bone. Natural birth buckets remain 0–9999 and their legendary probability stays 0.06%. The special coat is retained in memorial records.

The offline script create-diamond-rat.ts adds exactly one neonatal rat, uses healthy living adult parents, registers nursing and offspring, updates the birth history and refuses duplicates (including memorial records). It does not mint ownership or grant immortality. Ordinary biology and care apply. Apply only with an archived state and database row lock.
